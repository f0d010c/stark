# Support

Use [GitHub Discussions](https://github.com/f0d010c/stark/discussions) for usage questions, design examples, and ideas.

Use [GitHub Issues](https://github.com/f0d010c/stark/issues) for reproducible bugs, routing failures, broken references, or packaging problems. Include the prompt, expected route or behavior, actual result, Stark version, host agent, and relevant output.

Report security problems privately as described in [SECURITY.md](SECURITY.md).
