# Motion recipes

Use these after `references/ui-patterns/motion-library-playbooks.md` when a project needs implementation-shaped motion guidance.

Recipes are not effects to paste everywhere. Choose one or two that support the product object, user mode, and motion thesis.

## Recipe brief

```md
Motion recipe
- Product job:
- Library/API:
- Trigger:
- State owner:
- Accessibility:
- Performance traps:
- When to remove:
```

## Recipes

- `layout-transition.md` - Motion layout continuity for cards, sheets, tabs, and detail views.
- `command-palette-motion.md` - fast command palette open/filter/execute feedback.
- `run-timeline-arrival.md` - long-running agent/tool progress and artifact arrival.
- `route-view-transition.md` - route/detail continuity with View Transitions or Motion.
- `pinned-product-story.md` - GSAP/native pinned proof sequence.
- `native-scroll-reveal.md` - CSS scroll-driven progressive reveal.
- `r3f-product-object.md` - inspectable Three/R3F product object.
- `rive-state-icon.md` - designer-authored state-machine icon/illustration.

## Selection rule

- Product app state: `layout-transition.md`, `command-palette-motion.md`, `run-timeline-arrival.md`.
- Marketing/product proof: `pinned-product-story.md`, `native-scroll-reveal.md`, `route-view-transition.md`.
- Spatial proof: `r3f-product-object.md`.
- Authored illustration state: `rive-state-icon.md`.
