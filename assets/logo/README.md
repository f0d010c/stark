# Stark logo

Primary small mark:

- `stark-mark.svg`

Small-size and favicon variant:

- `stark-favicon.svg`

Monochrome variant:

- `stark-mark-ink.svg`

## Concept

The mark is a compact UI grid interrupted by an ember spark. It represents Stark turning generic generated screens into product-specific design systems.

## Colors

- Ink: `#111313`
- Ivory: `#F7F1E6`
- Ember: `#FF4E2E`
- Optional teal accent for broader brand work: `#167C7A`

Use the ember spark sparingly. At tiny sizes, prefer the favicon SVG and avoid adding extra accents.
