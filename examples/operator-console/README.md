# Operator Console landing page

Standalone Vite/React marketing site for a fictional local-first AI-agent operations product.

## Run

```powershell
npm install
npm run dev
```

## Stark decision brief

- Surface type: marketing site with real product UI proof.
- Product thesis: local-first command center for installed/running AI coding agents, plugins, skills, MCP servers, credentials, hooks, installs, logs, and run history.
- Visual direction: industrial monospace, warm near-black, phosphorus green and amber semantic states, hard rule lines, no decorative color gradients.
- Density: operational density inside product proof, balanced narrative elsewhere.
- Hierarchy: first viewport anchors on a believable console preview; primary CTA is "Inspect local stack"; secondary CTA is "View run history".
- Component grammar: terminal shell, panes, tables, status rows, diffs, permission path lists, workflow code fragments.
- Responsive containment: dense rows and tables scroll inside bounded regions; mobile stacks panes without page-level horizontal overflow.
- Motion budget: subtle mechanical entrance and hover/focus transitions; reduced motion respected.
- State visuals: loading scan, stale token, permission blocked, warning hook, healthy server, empty cleanup queue, successful credential masking.
- Bans: no purple AI gradients, generic SaaS cards, placeholder images, fake social proof, decorative blobs, emoji, or "10x" copy.
