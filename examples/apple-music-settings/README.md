# Sample — Apple Music Settings (Resonance app)

Generated by `apple-design` skill applied to the brief: *"Settings screen for a music app on iOS 26 with Liquid Glass."*

## Direction

Refined editorial restraint. Lineage:
- **Things 3** — typographic clarity
- **Mela** — text-first, no chrome
- **Ivory** — haptic + symbolEffect choreography

## Idiom checklist (per `skills/apple-design/SKILL.md`)

| Rule | Applied? | Where |
|---|---|---|
| Liquid Glass on toolbar | Yes | `.toolbar { ... }` auto-lifts on iOS 26 |
| Liquid Glass on profile avatar | Yes | `.glassEffect(in: Circle())` |
| `GlassEffectContainer` for floating pill | Yes | `NowPlayingPill` |
| `.buttonStyle(.glass)` | Yes | Account button + play/pause |
| `.scrollEdgeEffectStyle(.soft)` | Yes | Replaces hard chrome |
| `@Observable` model | Yes | `SettingsStore` — no `ObservableObject` |
| `MeshGradient` background | Yes | Subtle, refraction substrate for Liquid Glass |
| SF Symbols 7 only | Yes | All icons via `Image(systemName:)` |
| `.symbolEffect(.bounce)` / `.replace.byLayer` | Yes | Checkmark + play/pause toggle |
| Font.TextStyle (Dynamic Type) | Yes | `.font(.body)`, `.font(.caption)` — no hard points |
| System semantic colors | Yes | `Color(.systemPurple)`, `.primary`, `.secondary`, `.tertiary` |
| Spring physics only | Yes | `.spring(response:dampingFraction:)` everywhere |
| `accessibilityReduceMotion` honored | Yes | Mesh gradient dampens to 0.4 opacity |
| Accessibility labels | Yes | `.accessibilityLabel` on icon-only buttons |
| `.searchable` (Liquid Glass pill on iOS 26) | Yes | Top-level search |
| `.presentationDetents` if modal | N/A | No sheets in this screen |
| `.contentTransition(.numericText(...))` | Yes | Crossfade slider value |
| Grouped Form / List idiom | Yes | `.listStyle(.insetGrouped)` |
| Section headers in tracking + caps | Yes | `SectionHeader` view |

## Anti-slop rejections

| Banned pattern | What I used instead |
|---|---|
| Inter / Roboto | SF Pro via `Font.TextStyle` (system) |
| Material elevation shadows | Liquid Glass + materials (`.ultraThinMaterial`) |
| Hamburger menu | `NavigationStack` push with `searchable` |
| FontAwesome / Material Symbols | SF Symbols 7 only |
| Linear / easeInOut animation | `.spring(response: 0.4, dampingFraction: 0.85)` |
| `.padding(20)` magic numbers | System spacing + 8/16/24 grid |
| Custom toggle UI | Native `Toggle` — system handles platform |
| Hardcoded hex `#3b82f6` etc. | `Color(.systemPurple)`, `Color(.systemTeal)` etc. |
| Ignoring safe areas | Background uses `.ignoresSafeArea()`, content respects insets |

## Build

Requires Xcode 26 + iOS 26 SDK. Add `SettingsView` to a `WindowGroup` and run.

```swift
@main
struct ResonanceApp: App {
    var body: some Scene {
        WindowGroup {
            SettingsView()
        }
    }
}
```
