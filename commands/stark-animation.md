# /stark-animation

Use this command when the user asks for high-end animation direction, Luma-level landing pages, cinematic product reveals, or when an animated design feels messy, copied, cheap, or like random elements were pasted around a hero.

Read, in order:

- `references/ui-patterns/design-orchestration.md`
- `references/ui-patterns/reference-board-workflow.md` when references or inspiration are involved
- `references/ui-patterns/animation-creation.md`
- `references/ui-patterns/premium-animation-direction.md`
- `references/ui-patterns/choreography-state-machine.md`
- `references/ui-patterns/motion-pattern-atlas.md`
- `references/ui-patterns/motion-library-playbooks.md`
- `references/ui-patterns/advanced-visual-systems.md` when shader/canvas/WebGL/Spline/Rive/Lottie/video/generated key art is central
- `references/ui-patterns/performance-budget-contract.md` when the animation uses expensive media, WebGL/canvas, stacked libraries, or large assets
- `references/ui-patterns/qa-evidence-contract.md`

Return:

```md
Stark animation direction
- Product truth:
- Main object:
- Signature transformation:
- Visual world:
- Repeated motif:
- Proof surface:
- Copy voice:
- Motion grammar:
- Advanced visual mechanic:
- Asset quality plan:
- Library ownership:
- Rejected reference/libraries:
- Mobile/reduced-motion plan:
- QA evidence:
```

Hard fail if the result is just floating props, copied reference identity, generic hero copy, library stacking, or motion without product proof.
