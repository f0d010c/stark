# /stark-reference-board

Create a reference board before designing.

Use when the user asks for research, inspiration, shipped-product references, high-craft visual quality, or "like X but original."

Read:

- `references/ui-patterns/reference-board-workflow.md`
- `references/ui-patterns/reference-analysis.md`
- `references/ui-patterns/research-synthesis-contract.md`

Output:

```md
Reference board
- Product category:
- User mode:
- Risk level:
- References:
- Structural lessons:
- Visual/material lessons:
- Motion/choreography lessons:
- State/recovery lessons:
- Responsive lessons:
- Asset/media lessons:
- What not to copy:
- Decisions Stark will use:
- Research synthesis required:
```

Rules:

- Prefer 3-5 references when practical.
- Include at least one state/recovery lesson for product UI.
- Extract structure and interaction, not trade dress.
- Name what will be changed before implementation.
